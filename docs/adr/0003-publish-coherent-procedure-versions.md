# Publish coherent Procedure Versions

A Procedure Version is an immutable semantic snapshot of rules, bilingual guidance, and public provenance; meaning-changing edits and newly public evidence create a new version. At most one published version is applicable to a Procedure on a date, although future-effective versions may be scheduled. Publication workflow is separate from calculated trust, so stale claims make only dependent results inconclusive; withdrawn versions remain addressable for historical evaluation but are never selected for new plans.
