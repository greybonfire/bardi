# Do not persist case Facts in version 1

Anonymous Case Facts are evaluated by a stateless server module and discarded after the request or short session; request bodies must not be logged. Product analytics retain only minimized events and coarse non-sensitive metadata. Optional follow-up contact is purpose-limited and linked only to plan metadata through a random token, never to raw Facts. This limits diagnostics and longitudinal personalization in exchange for materially lower privacy and security exposure.
